# Italian
This repo stores notes from Italian language classes. 

* Get the PDF from the pdf folder tree.
* Get the Anki file from the anki folder.

The PDF is built from LaTeX notes in the latex folder tree.
The LaTeX will always be more up to date than the PDF.

The A1A2 material is sourced in Markdown (md) and
a shell script (sh) calls pandoc to convert it to epub,
with a yaml metadata file.
