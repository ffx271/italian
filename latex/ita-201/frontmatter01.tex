\section{How to use this Guide}
\label{how-to-use-this-guide}

This guide covers all the grammar, vocabulary and expressions from an
A1-A2 Italian course. Each section includes the core rule, key
examples, and common pitfalls to avoid. Use it for revision, quick
reference, or as a checklist before tests.
